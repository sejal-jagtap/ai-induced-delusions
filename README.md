# The Spiral: AI-Induced Delusions

An interactive classroom game for a Duke data ethics case-study session on **Human–AI Interaction Vulnerabilities**.

Players join "Lumen AI" (a fictional chatbot company) as a new data scientist and work through five levels on how chatbots can co-create delusional beliefs, and what the people who build them should do about it.

## Levels

| # | Level | What players do | Discussion question |
|---|-------|-----------------|---------------------|
| 1 | Spot the Spiral | Flag risky vs healthy chatbot replies in a chat log | Warm-up |
| 2 | Size the Risk | Judge what the real statistics prove and pick the data needed | How concerned should we be, and what would we need to know? |
| 3 | Build the Guardrails | Ship 3 safety features and face their downsides | Most promising fixes and their downsides |
| 4 | Who's Responsible? | Assign responsibility in four scenarios | How responsible are data scientists and developers? |
| 5 | Ship or Stop | Make three product calls and choose team principles | Which principles should the team never lose sight of? |

## Features

- XP, badges and ranks
- Hints and skip on every level
- Facilitator mode with timings and talking points
- A results summary players can copy for discussion
- Works on desktop and mobile

## Run it

It's a single self-contained `index.html` with no build step. Open it in a browser, or deploy it as a static site (e.g., on Vercel with Framework Preset set to **Other**).
